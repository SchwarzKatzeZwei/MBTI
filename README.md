# 16タイプ分析

自分の傾向を4つの軸から読み解く、オリジナルの自己理解用Webアプリです。

## 方針

- 32問（4軸×8問）を7段階で回答します。
- 各軸の回答を合算し、傾向の強さと16文字の組み合わせを表示します。
- これは公式のMBTI検査ではなく、診断・医療・心理検査の代替ではありません。
- 回答はブラウザ内で処理し、サーバーへ送信しません。

## 正確性について

現在の実装は、回答しやすさと4軸のバランスを重視したプロトタイプです。信頼性係数、再検査信頼性、他の指標との妥当性、対象者を増やした項目分析はまだ実施していないため、「正確な診断」とは表現しません。実運用前には、同意を得た匿名データでこれらを検証し、設問と採点を改訂する必要があります。

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build` です。
